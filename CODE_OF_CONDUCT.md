# Code of conduct

We want a welcoming project for contributors of all backgrounds and experience levels. Be respectful, give constructive feedback, credit others, and discuss ideas without attacking people. Allow space for questions and corrections.

Harassment, discrimination, threats, sexualized attention, doxxing, and sharing private information without permission are unacceptable in issues, pull requests, discussions, and other project spaces.

Maintainers may edit or remove inappropriate content, request a change in behavior, or restrict participation according to severity and repetition. Apply these expectations consistently and handle private reports discreetly.

A private conduct-reporting contact must be configured by the owner before launch. Until a contact is available, request a private channel without posting sensitive details publicly. Do not use GitHub vulnerability reporting for interpersonal conduct reports. No response deadlines are promised.
