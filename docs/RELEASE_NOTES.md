# Browser Assistant 2.7.7

- The online IDE opens while the answer is generated and reviewed. This removes the separate wait before requesting a solution. Actual answer time depends on the model and connection.
- Supported Node.js practice questions can open the IDE, write to an empty `app.js`, check JavaScript syntax, and run the portal's grading command. Existing code is preserved. The automatic IDE flow is covered by fixture tests; a live automatic submission has not been verified.
- Includes the earlier fixes for complete code snippets, chart capture and answer checks, and practice navigation.

Download the extension and backend ZIPs and follow the [setup guide](https://github.com/JaswanthCodeHub/browser-assistant/blob/main/README.md#first-run). Reload an existing unpacked extension after updating. Downloads include SHA-256 checksums. Provider keys, logs, and local history are excluded.

See the [changelog](https://github.com/JaswanthCodeHub/browser-assistant/blob/main/CHANGELOG.md) for earlier changes.
